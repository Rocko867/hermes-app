Datenschutzerklärung

Hermes ist ein privater KI-Assistent, der ausschließlich vom Betreiber (Sebastian, sebster96@googlemail.com) für sein eigenes Google-Konto genutzt wird.

Welche Daten werden verarbeitet?

Mit Zustimmung des Betreibers liest Hermes über die Gmail API (Berechtigung gmail.readonly) E-Mails aus dem eigenen Postfach des Betreibers. Es werden keine E-Mails gesendet, verändert oder gelöscht.

Wofür?

Ausschließlich, um dem Betreiber Inhalte seines Postfachs zusammenzufassen und Fragen dazu zu beantworten.

Weitergabe und Speicherung

Daten werden nicht verkauft und nicht an Dritte weitergegeben, außer an den vom Betreiber gewählten KI-Modellanbieter zur Verarbeitung seiner eigenen Anfragen. Zugangstoken werden lokal auf dem Rechner des Betreibers gespeichert. Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

English summary: Hermes is a private assistant used only by its operator for his own Google account. It requests read-only Gmail access (gmail.readonly), never sends, modifies or deletes mail, does not sell or share data, stores tokens locally, and complies with the Google API Services User Data Policy including Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: sebster96@googlemail.com
